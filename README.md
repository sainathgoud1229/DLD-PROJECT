# LED Rhythm Challenge – DLD Project

**Digital Logic Music & Game Combo – LED Rhythm Challenge**  
A fun interactive project that combines **Digital Logic Design (DLD)** concepts with a music-style rhythm game using LEDs and Node.js. The goal of this project is to create a game where LEDs light up in sync with beats, and the player interacts based on rhythm. :contentReference[oaicite:1]{index=1}

---

## 📌 Project Overview

This project is designed as part of a **Digital Logic Design (DLD)** course submission. It uses a **Node.js backend** to serve the game logic and coordinate LED patterns that respond to musical rhythms. Players interact through a front-end interface while LEDs flash in rhythm to create an engaging and educational experience. :contentReference[oaicite:2]{index=2}

---

## ⚙️ Features

✅ Rhythm-based LED flash game  
✅ Server logic written in **Node.js**  
✅ Uses **Express.js** for routing  
✅ LED patterns synchronized to audio beats  
✅ Easy to run and play on local machine
